# 机器人越障赛场地过程式生成与考核系统

面向机器人工程实训课教师的桌面 Web 应用：按场地尺寸、难度系数、障碍序列**过程式生成**
台阶 / 斜坡 / 梅花桩 / 窄桥 / 碎石地五类单元，支持学员调整与锁定、3D 检视、模型与参数表
导出，以及学员方案自动判分 + 教师复核的完整考核闭环。

技术栈：**Svelte 4 + TypeScript + Babylon.js 7 + Vite 5**，纯前端、零后端，
数据通过 `localStorage` 持久化。

## 启动

```bash
npm install
npm run dev        # 开发，默认 http://localhost:5173
npm run build      # 生产构建到 dist/
npm run check      # svelte-check 类型检查（0 error）
npm run test:smoke # 核心逻辑冒烟测试（11 项）
```

## 功能与操作

### 场地编辑页
- **场地参数**：长 / 宽（mm）、难度系数（0.1~1.0）、整数随机种子、障碍序列（可增删、调序、重复）。
- **生成新场地**：同一种子 + 同一序列 + 同一参数，生成的布局与所有高度**逐字节一致**。
- **重新生成（保留锁定）**：已「锁定」单元的位置/旋转/尺寸/参数原样保留，其余单元重排并自动绕开锁定单元。
- **单元编辑**：3D 视图点选单元后用 Gizmo 拖动改位置（100mm 吸附）、绕 Y 轴旋转（15° 吸附）、
  三轴缩放改尺寸；也可在右侧面板精确输入。缩放会自动回写派生参数（如坡度角、单级台阶高度）。
- **线框模式**：一键切换实体线框化，显示每个单元的包围盒与坡度/高度/通道宽度标注牌（始终朝向相机）。
- **场地网格**：按 1000mm 分块，使用 Babylon **ThinInstance 薄实例**一次绘制，棋盘着色。
- **导出**：
  - `GLB`：Babylon GLTF2 序列化，自动剔除包围盒/标注等辅助节点，单位毫米；
  - `CSV 参数表`：含每个单元的坐标、旋转、占地、坡度、障碍高度、通道宽度与详细参数，带 UTF-8 BOM 可直接用 Excel 打开。
- **题库**：当前场地可命名保存为题目，随时载入或删除。

### 学员提交页
学员填写机器人方案（最大越障高度、最大爬坡角、最小通道宽度、轮径、车体尺寸、方案说明），
提交后立即自动判分（占 **70 分**）：

| 判据 | 适用单元 | 规则 |
| --- | --- | --- |
| 坡度 | 斜坡 | 单元坡度 > 方案最大爬坡角 → 不通过 |
| 障碍高度 | 台阶、碎石地 | 单级高度/最大石块 > 最大越障高度 → 不通过 |
| 通道宽度 | 梅花桩（桩间净距）、窄桥（桥面宽） | 通道 < 方案最小通道宽度 → 不通过 |
| 全场通道 | 全部单元 | 任意两单元间真实最小净距（凸多边形距离）< 需求 → 不通过 |

页面同步给出逐项判据明细与按类型聚合的错题汇总。

### 教师复核页
- 成绩册列出所有提交：自动分、复核分、总分、错题数、时间；
- 教师查看方案参数与自动判分明细，按 0~30 分滑块打复核分、写错题讲解评语；
- 总分 = 自动分（70）+ 复核分（30）；
- 一键导出**成绩与错题汇总 CSV**（含每题不通过明细与教师评语）。

## 确定性（同种子可复现）如何保证

- `src/lib/rng.ts`：`mulberry32` 确定性 PRNG，无 `Math.random()` 参与布局；
- 每个单元拥有独立随机流 `unitRng(seed, rngIndex)`，其参数与高度只取决于 `(seed, rngIndex)`，
  与生成顺序、其他单元是否锁定无关；
- 布点在固定候选网格上做 Fisher–Yates 洗牌，旋转角在洗牌前一次性确定，
  碰撞重试不会消耗额外随机数；
- 碎石地石块的位置/尺寸/朝向由同种子派生的独立流生成；
- 冒烟测试第 1、4 组断言：同种子两次生成 `JSON.stringify` 完全相等，
  且经过「锁定 → 重排」后再次全量生成仍与首次完全一致。

```

  lib/
    types.ts          领域模型与标签
    rng.ts            确定性 PRNG
    geometry.ts       旋转矩形 SAT 碰撞、场内判定、凸多边形通道净距
    generator.ts      五类单元参数生成 + 确定性布点 + 锁定重排
    evaluation.ts     坡度/高度/通道自动判分（70 分）与错题汇总
    exporters.ts      场地参数表 / 成绩册 CSV
    stores.ts         Svelte store、localStorage 持久化、出题/提交/复核动作
    babylon/
      unitMesh.ts     五类单元的确定性几何、材质、包围盒、标注牌
      CourseRenderer.ts 场景、薄实例网格、Gizmo 编辑、线框切换、GLB 导出
  components/         ConfigPanel / UnitPanel / View3D / ExportBar / StudentSubmit / TeacherReview
scripts/smoke.ts      核心逻辑冒烟测试
```

## 约定与限制

- 全系统长度单位毫米（mm），角度单位度（°）；
- 单元间最小净距 500mm、距场地边缘 300mm；场地过小导致无法满足时取最优候选并允许挤压（可在参数表中复核）；
- 目前为单机本地应用，多机共享题库/成绩可通过导出的 CSV 与 GLB 离线交换。

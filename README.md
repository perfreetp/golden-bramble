# 藤编纹样工作室（Rattan Weave Studio）

仿藤塑料户外家具厂的编织纹样过程式生成工具。原生 TypeScript + Web Components + PixiJS，无框架。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 生产构建
npm test         # 核心逻辑自检（确定性 / 锁定 / 手工项 / 拼片用量）
```

## 功能对照

| 需求 | 实现 |
| --- | --- |
| 三种编织规则 | 经纬编织（平纹）/ 斜纹（2/1，飞数可调）/ 六角网（隔根错位留孔），见 `src/core/pattern.ts` |
| 参数生成整幅 | 经密、纬密（根/10cm）、带材宽度（mm）、幅面尺寸、色带组，一铺整张床头面/椅面 |
| 完全可复现 | `种子 + 全部参数` 经 FNV 哈希派生 mulberry32 随机流，同种子同参数结果逐单元一致（有测试） |
| 滚轮缩放看压叠 | PixiJS 画布滚轮以指针为中心缩放（15%–6000%），被压段变暗、压上段带高光棱线 |
| 锁定区域重掷 | 「锁区域」模式拖矩形，重掷种子时锁定区压叠与带材颜色保持不变 |
| 手工项保留 | 「改压叠」点单元翻转、「改色」点带材刷当前色带；重新生成不丢，画布上以粉点/三角标出 |
| 色带实时预览 | 色带组可换色、滑杆调占比（占比决定色段宽窄），改动即时重生成 |
| 拼片裁切 | 按实际尺寸（拼片边长 mm）切分，画布标拼缝线与编号，清单给出每片位置/尺寸/拼缝/分色带材用量（米） |
| 导出 | 拼片清单 CSV / JSON，整幅预览 PNG |
| 订单工作流 | 客户下单建项目（床头面/椅面分条目，各带截止时间与参数快照）→ 制作员开始/提交 → 主管通过或退回（记返工次数）→ 全部通过后打包交付（交付记录带截止时间） |

## 结构

```
src/
  core/    rng.ts（确定性随机）types.ts（模型）pattern.ts（生成/锁定/手工）tiling.ts（拼片与用量）
  render/  WeaveRenderer.ts（PixiJS 画布：编织体 + 拼缝/锁定/手工标记叠加层）
  state/   store.ts（全局状态 + 订单工作流，localStorage 持久化）
  ui/      app-shell / param-panel / band-editor / canvas-view / tile-panel / project-panel
scripts/   test-core.ts（核心自检）
```

## 说明

- 订单条目保存下单时刻的参数快照，后续改画布参数不影响已建项目。
- 参数与项目存于浏览器 localStorage；清缓存即重置。
- 六角网规则下的孔洞不计入带材用量（按孔洞比例扣减）。

# 机器人舞蹈 2D 骨骼动画制作与考核平台

面向机器人舞蹈团教学的纯前端平台：学员在编辑器里拆分机器人部件、绑定骨骼层级、带旋转限位地编排挥手舞蹈、打关键帧并调节插值曲线，完成后提交；系统自动评分、教师复核，成绩与错题按班级汇总。

- **技术栈**：原生 TypeScript（strict）+ Web Components（Shadow DOM）+ WebGPU，零运行时框架依赖
- **渲染**：自写 WebGPU 2D 即时模式渲染器；`navigator.gpu` 不可用时自动降级到同接口的 Canvas2D 渲染器，功能完全一致
- **持久化**：localStorage（任务 / 工程 / 提交 / 班级），内置演示种子数据，顶栏可一键重置

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173 ，esbuild 监听热更新
```

其他命令：

```bash
npm run typecheck  # tsc 严格类型检查
npm run build      # 产出 dist/bundle.js + bundle.css
npm test           # Node 单元测试（FK/限位/吸附/贝塞尔/时间轴/评分，11 项）
npm run e2e        # 自拉起 headless Chrome 跑主冒烟 + 9 项交互验收
```

## 四个界面

| 路由 | 界面 | 能力 |
| --- | --- | --- |
| `#/tasks` | 任务大厅 | 教师布置任务（rubric 表单）；学员开始/继续编辑、查看提交状态 |
| `#/editor/:taskId` | 动画编辑器 | 骨骼层级、WebGPU 视口、时间轴、曲线面板、导出与提交 |
| `#/review` | 考核评分 | 自动评分明细、逐帧回放、教师 40 分复核打分与错题标注 |
| `#/dashboard` | 班级汇总 | 成绩分布、错题排行、学生明细表、CSV 导出 |

顶栏可切换 **学员 / 教师** 角色；学员端还可在任务大厅切换当前学员身份。

## 编辑器核心交互

- **部件与层级**：基座 → 腰 → 头，腰 → 左右大臂 → 小臂 → 腕 → 夹爪共 11 根骨骼；支持改名、改限位、重新绑定父级（防循环）、增删子骨骼
- **FK 联动**：拖任意骨骼只改其局部角，子骨骼经正运动学自然跟随；视口高亮选中骨骼并显示环形旋转手柄，后代关节描边提示联动
- **旋转限位 + 5° 吸附**：拖拽角度先吸附到 5° 整数倍，再按每关节 `[min,max]` 钳制；超限被卡住并弹出红色限位提示与限位弧
- **时间轴**：每骨骼一条轨道，菱形关键帧按插值类型着色；支持多选、复制 / 粘贴（跨骨骼）、整体平移、双击打点、刮擦、按工程 fps 逐帧播放
- **三种插值**：线性、缓入缓出（三次 smoothstep）、自定义三次贝塞尔；曲线面板可拖两个手柄，实时显示当前帧角速度、段平均速度与逐帧速度柱状图
- **跳变帧标红**：逐帧计算角速度，相邻帧速度差超过任务阈值的帧在轨道上标红，并计入自动评分扣分项
- **导出**：工程文件 `.rdproj.json`（可再导入）、序列帧精灵图 PNG + 帧索引 JSON

## 评分模型

- **系统自动评分（60 分）**：关键帧数量 15 + 关节角度范围 15 + 时长符合度 15 + 动作流畅度（跳变帧扣分）15
- **教师复核（40 分）**：回放作品后滑块打分，勾选错题标签（限位违规 / 曲线突变 / 帧数不足等）并写评语
- 最终成绩 = 自动分 + 教师分，班级汇总页按成绩段分布与错题类型聚合

## 目录结构

```
src/
  core/        类型、数学、插值(easing)、store、演示种子
  gpu/         Renderer 接口 + WebGPU/Canvas2D 双实现
  skeleton/    FK 求解、限位、命中测试、机器人骨架预设、绘制
  anim/        时间轴操作、跳变检测、自动评分、序列帧导出
  components/  9 个自定义元素（4 个屏幕 + 视口 + 3 个面板 + 外壳）
tests/         Node 单元测试
scripts/       dev server、CDP 冒烟/交互/e2e 验证脚本
```

# 宠物救助站 · 分层收容笼舍平面图渲染工具

Svelte 4 + Vite + WebGPU(自动回退 Canvas2D)。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建
npm run preview  # 预览构建产物
```

## 功能

### 地图(MapView + WebGPU 实例化渲染)
- 1344 个笼位(A/B/C/D 四区,24×14/区)+ 隔离间 ×3、医疗间、洗消间、3 条通道、24 个摄像头点位
- 图层开关:笼位层 / 隔离层 / 设备层 / 通道层
- 视口裁剪:每帧只向 GPU 提交可见实例,单次 draw call
- 缩放 LOD:
  - 最远(<6x):只显示区域色块与功能房间
  - 中等(6–20x):笼位轮廓 + 编号
  - 最近(>20x):动物照片缩略图、隔离标记 ⛔、7 天观察到期日(逾期红色)
- 滚轮缩放(以光标为中心)、拖拽平移、HUD 复位视图
- 悬停信息卡;单击选中高亮;Shift+拖拽(或 HUD 框选按钮)框选批量改状态
- 状态颜色 + 角标:空置(灰)/ 在住(蓝 🐾)/ 隔离观察(橙 ⛔)/ 待领养(绿 ⭐)
- 顶栏搜索编号 → 自动定位并闪烁 6 秒

### 业务流(侧面板)
- **入站建档**:编号自动生成,照片(emoji)+ 滤镜加工,分配空置笼位;每次加工生成新版本,可比对最近两版生成差异报告
- **档案检索**:按品种、入站日期区间、笼位多条件过滤(仅已归档)
- **审批工作流**(右上角切换角色):
  - 收容员:建档、提交隔离申请、申请归档
  - 兽医:确认解除隔离
  - 站长:审核归档

## 结构

```
src/lib/data.js     世界布局与模拟数据(确定性随机种子)
src/lib/store.js    Svelte stores + 业务动作
src/lib/render.js   WebGPU 渲染器(WGSL)+ Canvas2D 回退,统一接口
src/components/MapView.svelte   画布、覆盖层标签、交互
src/components/SidePanel.svelte 图层/建档/检索/审批四个页签
```

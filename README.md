# 宠物咬胶 · 体素造型台

SolidJS + three.js 实现的宠物咬胶玩具体素建模台，供玩具厂造型组使用。

## 运行

```bash
npm install
npm run dev      # 开发，默认 http://localhost:5173
npm run build    # 产出 dist/
```

## 功能

**建模台**
- 新建模型时选定体素栅格：8mm（常规）/ 4mm（精细），自定义 X/Y/Z 格数
- 分层视图按 Z 层逐层编辑，可只看当前层（隐藏其他层），非当前层半透明显示
- 画笔三模式：加法 / 减法 / 上色，颜色走玩具厂色卡（10 色）
- X / Y 两个方向镜像对称，改一侧另一侧实时跟着变
- 框选体素块：复制 / 剪切位移 / 删除；粘贴前显示落点轮廓（绿=可落下，红=占用冲突），有冲突不能落下
- 整体变换：绕 X/Y/Z 旋转 90°、沿 X/Y/Z 镜像翻转、缩放 ×2 / ×½
- 收尾网格化：体素贪心合并成网格，按角度阈值 + 最小边长减面，面数实时显示
- 导出 GLB / OBJ，材质名与网格名带色卡名

**批次质检**
- 一批模型一键自动跑检查（连通性、尖细结构、尺寸规格、面数、颜色数等）
- 问题分「严重 / 不建议」两级，复核员逐条确认或驳回
- 全部复核完且无确认的严重问题才能放行；不达标退回供应方并记返工次数
- 每批有截止时间，逾期红字提醒；数据存 localStorage

## 操作

左键绘制 · 右键旋转视角 · 滚轮缩放 · 中键平移 · Esc 取消粘贴/选区

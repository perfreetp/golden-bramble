# 兽医助理培训 · 二维角色骨骼动画编辑器

面向兽医助理实训教学的纯前端二维骨骼动画工具：导入犬只侧面图后手动拆件、绑定父子骨骼、
打关键帧制作保定/包扎/采血动作，系统自动评分并由老师复核，成绩单汇总每个动作的扣分点。

技术栈：**React 18 + Canvas2D + OffscreenCanvas（不支持时自动回退普通 canvas）+ Vite**，
数据持久化用浏览器 IndexedDB，无后端依赖。

## 启动

```bash
npm install
npm run dev        # 开发服务器（默认 http://127.0.0.1:5173）
npm run build      # 生产构建
npm test           # 32 个纯逻辑单元/端到端测试（node --test）
```

## 完整工作流

### 1. 导入素材与手动拆件
- 顶栏「导入犬只侧面图」选择本地图片，或点「生成示例犬」用内置 Canvas 程序化示意图练习。
- 拆件工作台中用**多边形套索**单击加点，点击金色首点或双击闭合，离屏抠图（`OffscreenCanvas`
  的 `convertToBlob`）生成带透明通道的部件 PNG；环境不支持时自动回退到 `HTMLCanvasElement`。
- 部件类型：头、前肢、后肢、尾巴、保定带（另含躯干/其他）。建议按该顺序圈选。

### 2. 锚点与父子骨骼
- 每个部件有独立**锚点**：左栏「锚点模式」可直接在画布上拖，或在右侧属性面板输入坐标。
- 属性面板选择**父部件**完成骨骼绑定（内置防环校验，不能把后代设为父级）。
- FK 求解用 3×2 仿射矩阵沿层级复合：父锚点即子关节中心。

### 3. 关节角度限制
- 每个部件可启用关节限角并设置最小/最大角度（滑块或数值）。
- 画布上拖动旋转采用**增量旋转**（指针方位角差值累加，与部件图朝向无关），
  子部件的相对角超出范围会被自动钳制；选中部件时画布显示限角圆弧与当前角度指针。
- 新建部件按类型给默认限角（如前肢 ±70°、头部 ±45°）。

### 4. 时间轴与关键帧
- 选中部件后在时间轴「打关键帧」，记录位置、旋转、缩放（同一帧重复打为覆盖更新）。
- 三种插值，在关键帧菱形的浮层菜单切换：
  - **线性**：匀速；
  - **贝塞尔**：cubic-bezier 双控制点，点「曲线编辑器」拖 P1（缓入）/P2（缓出）手柄，
    控制点 x 限制 0–1 保证时间单调，y 可超出形成过冲，内置 5 个预设；
  - **阶跃**：保持前一关键帧值直到下一帧。
- 旋转插值走最短角度路径（359°→1° 转 2° 而不是绕一整圈）。
- 拖动标尺/轨道即可**实时预览**任意帧；循环播放支持 **0.5x–2x** 六档倍速。

### 5. 洋葱皮
- 开启后画布以蓝色（前帧）/红色（后帧）半透明叠加前后各 1–3 帧，便于对照姿态。

### 6. 导出
- **PNG 序列帧**：OffscreenCanvas 逐帧离屏渲染，JSZip 打包 zip（含 `manifest.json` 记录 fps/帧数）。
- **工程文件**：`.vetproj`（JSON），含全部部件图 dataURL、锚点、骨骼、关节限角、关键帧与贝塞尔手柄，
  可重新导入继续编辑。
- 工程同时自动保存到 IndexedDB（左栏「本地工程」可切换）。

## 教学任务与评分

顶栏切到「教学任务中心」，角色分学员端/老师端（本地切换，存 localStorage）。

1. **老师布置任务**：预置保定、包扎、采血三个动作任务，可新建任务并设定要求时长。
2. **学员提交**：以当前工程提交，立即得到自动评分。
3. **自动评分（占总成绩 60%，满分 100）**：

   | 维度 | 分值 | 依据 |
   |---|---|---|
   | A 部件完整性 | 15 | 五类部件是否齐全 |
   | B 时长合规 | 15 | 实际时长是否在要求 ±20% 内 |
   | C 关节角度范围 | 30 | 全程均匀抽检最多 24 帧，按违规帧比例扣分 |
   | D 关键帧与运动 | 20 | 运动部件 ≥2 关键帧且确有旋转/位移 |
   | E 动作特征 | 20 | 按动作语义：保定看保定带收紧+肢体稳定；包扎看缠绕+头部稳定；采血看前肢伸展+头尾稳定 |

   每条扣分都带具体明细（哪一帧、哪个部件、实际值/限值）。
4. **老师复核（40%）**：打分+评语，系统按 `自动×60% + 老师×40%` 合并最终成绩，可修改复核。
5. **成绩单**：按三个动作分别汇总均分、每个扣分点出现次数/累计扣分/典型问题，
   并给出跨动作高频错题排行。

```

├─ lib/

│  ├─ grading.js        自动评分、成绩合并、成绩单聚合
│  ├─ project.js        工程/部件/关键帧工厂、默认限角、种子任务
│  ├─ store.js          IndexedDB 封装
│  └─ demoDog.js        内置示例犬生成
├─ state/               editorStore（reducer）、playbackStore（播放/洋葱皮/编辑覆盖）

└─ test/                32 个 node --test 测试
```

## 关键设计说明

- **编辑姿态覆盖层**：有关键帧后，画布上拖骨骼不会直接污染工程数据，改动先进入播放上下文的
  覆盖层实时预览；打关键帧时才固化，跳帧自动失效。
- **渲染统一坐标系**：画布整体 `ctx.scale(viewportScale)`，部件矩阵、骨骼叠层、洋葱皮、限角弧
  全部在同一逻辑坐标系绘制，避免缩放不一致。
- **OffscreenCanvas 使用点**：拆件抠图与序列帧导出两处离屏渲染，均带 Canvas2D 回退，
  能力状态显示在拆件台顶部徽章和导出 manifest 中。

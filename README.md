# 水上乐园园区总图渲染与检修派单系统

面向水上乐园运营部的园区平面总图渲染与检修工单管理系统。React 18 + three.js（OrthographicCamera 俯视平面视图）+ zustand，模拟测绘底图含 **2820 个**按图层归类的构件（救生椅 / 灯杆 / 喷淋头 / 排水篦子 / 监控点位）。

## 启动

```bash
npm install
npm run dev        # http://127.0.0.1:5180
npm run build      # 生产构建
```

## 功能对照

### 地图渲染（`src/three/ParkMapEngine.js`）

| 需求 | 实现 |
| --- | --- |
| 全园/片区/池体三级视口 | 顶栏分段按钮 + 片区/池体下拉，相机 650ms 缓动飞行 |
| 全园只画点阵与池体轮廓 | `THREE.Points` 顶点着色按设备状态着色，池体仅描边 |
| 片区出构件图标和编号 | 每类设备一个 `InstancedMesh`（单 draw call），Canvas 覆盖层绘制编号 |
| 池体显示喷淋朝向与角度 | 覆盖层按 `device.angle` 画朝向箭头并标注角度（°） |
| 图层树单独开关 | 设备层 / 管线层 / 绿化层 / 警戒线层，设备层内再按 5 类细分 |
| 平移缩放贴 60 帧 | 实例化渲染 + 标注网格抽稀（每格仅留一个，选中强制保留），右上角实时 FPS |
| 点选高亮描边 + 弹窗 | 高亮环 InstancedMesh，弹窗显示编号、所属池体、上次检修日期、当前状态 |
| 框选整组改状态 | Shift 拖拽或框选模式，批量置状态 / 批量登记故障 |
| 管线按管径分色 | DN50–DN300 五档配色，线宽随管径变化 |
| 十字交叉自动断开 | 管线带高程 z，低高程管在与高高程管交点两侧自动留缝，表示上下层位 |
| 标注重叠抽稀 | 屏幕网格（片区 74px / 池体 58px）去重，选中构件的标注强制显示 |
| 编号飞行定位 | 顶栏搜索，支持 id 与编码精确/模糊匹配，自动切到池体级并居中 |
| 导出当前视口平面图 | WebGL 画布 + 标注覆盖层 + 标题合成 PNG 下载，供园务会使用 |

### 检修派单（`src/core/store.js` + `src/components/WorkOrders.jsx`）

状态机：`待派单 → 已派单 → 待质检 →（合格）已完成 /（不合格）返工中 → 再提交`

1. 前台在构件弹窗或框选批处理条登记故障，自动生成工单并把构件置为「故障」
2. 调度在工单页把待派单工单派给师傅，构件转「检修中」
3. 师傅填写检修说明并提交结果
4. 质检员抽查：合格则关闭工单、构件恢复正常；不合格打回，工单进入返工并累计返工次数
5. 看板（`Dashboard.jsx`）按师傅统计派单数、完成量、返工次数与**返工率**，并展示工单状态漏斗

### 数据与持久化

- `src/core/mockData.js`：确定性随机生成的测绘底图（6 片区 / 16 池体 / 2820 构件 / 36 条管线 / 绿化与警戒线），刷新后布局一致
- 设备状态覆盖与工单通过 localStorage 持久化，刷新不丢失；清除站点数据即可复位

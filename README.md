# 爬宠饲养箱剖面布光预览工具

基于 **原生 TypeScript + Web Components + SVG + D3** 的二维剖面布光设计与批次质检系统，无前端框架，Vite 构建。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 类型检查 + 生产构建
npm test           # 光照引擎/质检规则单元测试（16 项）
npm run test:e2e   # 端到端测试（需先 npm run dev，28 项）
```

## 功能清单

### 布光设计台
- **灯具库拖入**：UVB 灯管（线性光源）、加热灯（点光源聚光）、夜灯、LED 灯带，支持拖拽投放与点击投放
- **遮挡物**：躲避穴（全遮挡）、树枝（半透光软阴影）、水盆（近全遮挡）
- **自由调整**：拖动灯具/遮挡物改变位置与高度，选中灯后拖黄色手柄调照射角度
- **网格吸附 + 角度对齐**：位置按 5cm（可调）网格吸附，角度按 15°（可调）对齐，可开关
- **多灯照度叠加**：逆平方距离衰减 + 光锥余弦廓线 + 多光源采样叠加
- **软阴影与遮挡**：线段-矩形相交求透射率，点光源圆盘虚拟采样产生半影，线性光源多点采样
- **四时段时间轴**：早晨 / 正午 / 傍晚 / 夜间，每盏灯独立的时段开关组合，环境光随时段变化
- **D3 热力图**：对数色阶（inferno）铺设全场照度，阴影损失区差异化透明
- **区域统计**：左/中/右三区平均照度与地面 5cm 照度实时统计，**低于 200 lux 的区域红虚线框标暗区**
- **导出**：剖面布光图 SVG / PNG、四时段×三分区照度分区表 CSV（带 BOM，Excel 直开）、方案 JSON
- 撤销/重做（50 步）、Delete 删除、Ctrl+Z/Y、属性检查器精确数值编辑

### 批次质检台
- 质检员导入一批方案 JSON（支持多文件、单文件数组），系统自动执行全部检查规则
- 问题按 **⛔严重 / ⚠️主要 / 🔸一般** 三级分类，按方案分组
- 复核员逐条 **确认问题 / 驳回**，支持重新复核
- **放行闸门**：存在待复核项时放行/退回按钮禁用；全部复核后，无确认问题才可放行，存在确认问题则退回供应方
- 内置「生成演示批次」按钮，覆盖缺 UVB、夜间错开灯、角度异常等典型缺陷

## 物理模型说明

照度为二维剖面上的相对工程值：每盏灯定义参考距离处的轴上照度，按逆平方定律衰减，光锥内以余弦平方廓线收边；多灯照度线性叠加，遮挡物按材质不透光度（躲避穴 100%、水盆 90%、树枝 72%）对穿过的光线求透射率。该模型用于方案间横向比较与规则判定，非绝对光学仿真。

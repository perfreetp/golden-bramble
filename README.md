# ShotPose Studio · 射击姿势课件工坊

给射击俱乐部教练做**射击姿势课件**的 2D 骨骼动画编辑器 + 课件派单/质检流程。
前端 Vue 3 + Canvas 2D + OffscreenCanvas，后端一个零依赖以外的 Express 小服务（JSON 文件存储）。

## 启动

```bash
npm install
npm run dev      # 前端 vite (5173) + 后端 api (8799)
# 或者生产模式
npm run build && npm start    # 单端口 8799 同时提供 api 和页面
# 端口/数据目录可用环境变量覆盖：PORT=9000 DATA_DIR=./mydata npm start
```

打开 http://127.0.0.1:8799 （生产） 或 http://localhost:5173 （开发）。
演示身份在登录页直接选，无需密码。

## 功能地图

### 1. 分层部件导入 → 绑骨
- 左侧「分层部件」拖入 PNG（可多选）或点「载入示例部件」。
- 按文件名/语义自动识别 头 / 躯干 / 上臂 / 前臂 / 手 / 枪 / 髋 七类，识别不出会标黄提示手动指定。
- 「绑骨」模式下：
  - 拖**橙色锚点**靠近骨骼松手即挂骨（松手时最近的骨骼高亮绿色）；
  - 「锚点」工具：拖动锚点在本部件图内移动，画面位置不变；
  - 「部件」工具：整体拖动部件/微调位置；
  - `Shift` + 点击骨骼 = 直接绑到该骨骼。
- 右侧「骨骼层级」可拖动骨骼**调整父子关系**（含防环检测、双击重命名）；拖动到顶部区域可解除父子。
- 属性面板可改绑定骨骼、锚点坐标、层级 z、不透明度，**重新绑骨时保持画面世界变换不变**。

### 2. 摆姿势与数值微调
- 拖骨骼尾端手柄旋转；`Shift` 15° 吸附；拖髋部移动重心。
- 右侧「姿势数值」：躯干前倾、持枪臂抬起、前臂弯折、头部俯仰、手腕角度、枪口微调、**呼吸起伏**、重心左右/高低，滑杆 + 数值输入双向同步。
- 每根骨骼有可编辑的**关节活动范围**；超出时骨骼标红、画布上出现红色限幅扇形与超限角标、顶部红条提示、右侧警告条，拖动松手时弹 toast。
- 呼吸起伏是程序化正弦叠加到重心偏移上，可直接打帧。

### 3. 时间轴 / 关键帧 / 插值
- 24 fps，动作段长度可调（默认 96 帧）。
- 每个通道一行轨道：双击轨道或点行内 ◆ 打关键帧，拖动关键帧改帧号，`K` 打全部通道关键帧。
- 三种插值：**线性 / 缓入缓出 / 贝塞尔**，可全局设置、按关键帧设置（轨道里有「本帧插值」）。
- 曲线编辑器：曲线绘制、关键帧拖动、**贝塞尔控制点拖动**、P1/P2 数值输入、回弹/急停等预设曲线，并标出该关节的上下限红线。
- 一段姿势可**存为预设**（记录相对首帧的偏移），套用到当前或任意动作段的任意帧；预设也会进「预设库」页面。

### 4. 预览与导出
- 左下「离屏预览」用 **OffscreenCanvas** 渲染（单帧 ~0.2ms，播放稳定 24fps），与时间轴共享同一个播放时钟；播放时不重绘 UI 只重绘离屏画布，所以拖动不掉帧。
- 洋葱皮（前 6 帧半透明）辅助对位。
- 导出 **PNG 序列帧 ZIP**（透明底，含 `manifest.json`：骨骼、插槽、关节范围、关键帧与插值）或 **关键帧 JSON**（全部动作段）。可选 0.5×/1×/1.5×/2× 分辨率。

### 5. 课件派单流程
1. **教练**「提交需求」→ 课件进入「待派单」。
2. **管理员**在看板抽屉里派单给制作者 → 「制作中」。
3. **制作者**在编辑器里做，保存工程到课件单，「提交质检」→「质检中」。
4. **质检**抽查：通过 →「已完成」；打回 →「返工中」且**返工次数 +1**，制作者可继续编辑再次提交。
5. 看板「统计」页：每人完成量、进行中、返工次数、**返工率 = 返工次数 / 提交次数**、完成率环形图、返工最多榜；「日志」页留痕全部操作。
- 后端强制角色权限（教练不能改工程、制作者只能改自己的单、只有质检能评审、且只能在「质检中」评审）。

## 目录

```
server/index.js        Express API + JSON 存储 (data/db.json)
src/rig/math.js        2D 仿射矩阵、贝塞尔缓动
src/rig/skeleton.js    静息骨架、绑骨/重挂、关节范围（带方向的 sign）
src/rig/renderer.js    部件/骨骼/网格/限幅绘制，renderFrame 统一渲染入口
src/rig/animation.js   关键帧轨道、采样、三种插值、预设、范围检查
src/rig/exporters.js   PNG 序列 ZIP / 关键帧 JSON
src/rig/sampleParts.js 程序化生成的示例分层部件
src/store/project.js   编辑器状态（rig / actions / live 拖动 / 撤销重做 / 预设）
src/store/playback.js  唯一播放时钟
src/components/*       StageCanvas / Timeline / CurveEditor / PropertiesPanel …
src/views/*            Login / Board / Editor / Presets
scripts/e2e.mjs        无头 Chrome 端到端测试（自带隔离服务与临时数据目录）
```

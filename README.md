# 笔杆雕刻纹样编辑与素材批次放行系统

面向毛笔厂笔杆激光雕刻的前端工作站：在笔杆**圆周展开图**上编辑贝塞尔纹样、做路径布尔运算、
检查激光可加工性，并对供应商批次素材执行三级自动检查与复核放行流程。

纯前端实现，**无需安装、无需构建、无需联网**（依赖已内置在 `vendor/`），双击 `index.html` 即可运行。

## 启动方式

- 直接双击 `index.html`（推荐用 Chrome / Edge 打开）。
- 若浏览器对本地文件有限制，可在本目录起一个静态服务：
  `npx serve .` 或 `python -m http.server`，然后访问提示的地址。
- 数据通过浏览器 localStorage 自动保存，刷新不丢失。

## 技术栈

- Vue 3（全局生产版，响应式数据/组件）
- D3.js（画布缩放平移 `d3.zoom`、指针坐标换算）
- paper.js（路径并集/差集/交集布尔运算）
- 原生 SVG（画布即 mm 坐标系，导出无损）
- 无打包工具，按模块拆分，依赖在 `vendor/`，离线可用

## 目录结构

```
index.html          入口页与全部 UI 布局
vendor/             vue / d3 / paper 本地依赖（离线）
js/
  model.js          数据模型、默认文档、localStorage 持久化
  geometry.js       贝塞尔 d 生成、采样、节点插入、断开闭合、环向环绕切分、吸附、接缝校验
  boolean.js        paper.js 布尔运算封装，保留原始路径 d
  gaps.js           <0.3mm 窄缝检测（空间哈希网格 + 尖角/邻接点排除）
  batch.js          批次三级自动分类、示例数据、文件下载
  editor.js         Vue 主应用：画布交互、撤销重做、阵列、SVG 导出、批次流程
```

## 功能与需求对应

### 一、展开图画布
- 输入笔杆**直径 Ø**，周长按 `C = π × 直径` 自动换算为展开长（也可手动改展开长）。
- 画布坐标单位即 mm，SVG `viewBox` 与导出尺寸一致。
- 按**环向等分数**绘制 0°–360° 参考线；另含水平中心线、首尾两条接缝（0 / 周长位置）。

### 二、贝塞尔路径编辑
- 「贝塞尔笔」单击落节点（直线段），双击 / Enter / Esc 结束；可在选中路径上继续绘制。
- 节点工具：**加节点**（最近线段上保形插入，含三次贝塞尔 de Casteljau 切分）、
  **断开节点**（闭合路径打开 / 开放路径切成两条）、**闭合路径**。
- 拖动节点与控制柄；控制柄默认 C1 平滑镜像，按 Ctrl 拖动可打断镜像。
- **吸附**：拖动时自动吸附到网格点、中心线、其它路径端点，按 Shift 临时关闭。

### 三、布尔运算
- Ctrl/Shift 点选**两条闭合路径**，执行并集 ∪ / 差集 − / 交集 ∩（差集按选择顺序：先选 − 后选）。
- 运算后原始路径隐藏保留，结果记录来源路径名与**运算前的原始 d**，导出时写入归档图层。
- 运算完成自动触发窄缝检查。

### 四、窄缝检查（激光可加工性）
- 阈值固定 **< 0.30mm**（激光最小刀缝），检测到即在画布用红色连线+圆圈标红，
  右侧面板统计窄缝处数与最窄间隙。
- 算法对所有可见路径做 0.1mm 步长采样、空间哈希近邻搜索，并排除三类假缝：
  折线相邻采样点、同一尖角两侧邻点（含闭合路径首尾尖角、paper 微曲线采样）、重合/共线退化点；
  回弯内侧等真实窄缝（多点夹隔）仍会被检出。

### 五、环向阵列
- 「环向阵列×3」将选中纹样按 1/3 周长复刻三份；跨越 0/周长接缝的路径自动做**保贝塞尔形状切分**
  并回绕到对侧，保证三份首尾接得上。
- 右侧「环向接缝校验」列出各接缝端点的 y 向偏差，超 0.2mm 判为未对齐。

### 六、撤销重做
- 历史栈上限 100 步（满足 ≥50 步要求），Ctrl+Z 撤销、Ctrl+Y / Ctrl+Shift+Z 重做。

### 七、SVG 导出
- 保留**图层 `<g>` 分组**（与画布图层一致，隐藏图层带 `display="none"`）。
- 每条路径保留原始 `d`；布尔结果额外带 `data-original-paths`，并在独立隐藏图层
  「原始路径数据归档」留存运算前数据。
- 含直径/周长/高度/等分数 metadata 与参考线组，尺寸单位 mm。

### 八、素材批次放行
- 「批次放行」页可载入示例批次或导入 JSON。
- **自动检查三级分类**（阈值可调）：
  - 合格：最小线宽与断点数均达标；
  - 警告：任一指标超标但在 20% 容差内；
  - 退回：超容差，或线宽低于 0.3mm 物理极限。
- 复核员逐条「确认通过」或「驳回」；**驳回必须填写原因**，否则拦截。
- **整批全部处理完（无待处理）才允许放行**；放行单 JSON 只含复核通过项，交付雕刻组。
- 「导出退回清单」生成带整改原因的 JSON，返回供应商。

## 快捷键

| 按键 | 作用 |
|---|---|
| V | 选择/节点工具 |
| P | 贝塞尔笔 |
| Esc | 结束手绘 / 清除选择 |
| Enter | 完成当前手绘路径 |
| Del / Backspace | 删除选中节点（保留≥2点）或路径 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Shift（拖动时） | 临时关闭吸附 |
| Ctrl（拖控制柄时） | 打断控制柄平滑镜像 |
| 滚轮 / 中键右键拖动 | 缩放 / 平移画布 |

## 测试

端到端测试在 `../test/` 目录（与应用代码隔离），基于 puppeteer-core + 本机 Chrome：

- `node e2e.js`：34 项，覆盖周长换算、等分线、贝塞尔、断开闭合、环向切分、
  布尔运算、四类窄缝场景、撤销重做≥50步、吸附、批次三级与放行门禁、SVG 导出结构。
- `node interact.js`：15 项真实指针交互（手绘、拖节点、按钮、批次复核、文件下载）与截图。

窄缝检测为基于采样的近似算法，正式投产前建议再用激光刀路仿真软件做一次最终复核。

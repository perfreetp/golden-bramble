# 驾校训练场分层平面图渲染与科目教学 Web 应用

React 18 + TypeScript + Vite + three.js + Zustand 实现。面向驾校训练场的万级要素分层平面图渲染,
以及「教练发布任务 → 学员摆放提交 → 系统自动评分 → 教练复核 → 成绩单/错题导出」的科目教学闭环。

## 启动

```bash
npm install
npm run dev        # http://127.0.0.1:5180
npm run build      # 类型检查 + 生产构建
npm run smoke      # 端到端冒烟测试(需先启动 dev server,36 项断言)
```

## 渲染架构(`src/three/FieldScene.ts`)

- **正交相机顶视平面图**:`OrthographicCamera` 沿 -Y 俯视,鼠标滚轮缩放、右键/中键平移。
- **空间网格分块**:场地按 20m × 20m 切成 192 个 cell,每个 cell 持有本块要素的合并几何体
  (点要素 `InstancedMesh`、线要素合并 `LineSegments`、面要素 `ShapeGeometry`)。
- **视口剔除**:平移/缩放时只切换视口相交 cell 的 `visible`,视口外 cell 零绘制;状态栏实时显示
  「视口网格 x/192、视口要素 n/10741」。
- **三级 LOD**(按视口高度切换):
  - LOD0(≥120m):只画 cell 轮廓块 + 底图面要素轮廓;
  - LOD1(30–120m):点要素收敛为单色小点、线要素正常绘制;
  - LOD2(≤30m):绘制完整顶视符号(三角/圆/环/星形/矩形等 9 种)与文字标注;
    标注带同文字去重、世界间距去重和数量上限,防止叠字刷屏。
- **拾取**:屏幕像素容差换算为世界距离,支持点、线(点到线段)、面(点在多边形内)三类要素点选。
- **交互绘制**:左键拖框矩形框选、Shift+左键任意多边形套索(圈任务用)、青色高亮描边环、
  搜索定位黄色脉冲闪烁环。

## 功能清单

- 五图层开关与单要素显隐覆盖,**即时生效**(图层开关只走可见性切换,改图层触发分块重建)。
- 点选高亮描边,右侧栏弹出编号、类型、坐标、所属图层、可见性与业务属性。
- 框选/套索批量改图层、批量显示/隐藏、清除覆盖。
- 搜索框支持完整编号、编号前缀与标注名模糊匹配,定位后相机飞至要素并闪烁 3 秒。
- 教练端:Shift 套索圈出某科目的桩位与车道,填写标题/科目/教学要求后发布任务。
- 学员端:选择任务 → 摆放模式下选中目标要素并在图上落点 → 提交;提交前有实时预估分。
- 自动评分(`src/lib/grading.ts`):逐点计算偏差(点取欧氏距离,车道取点到线串最短距离):
  ≤0.15m 满分、≤0.3m 90、≤0.5m 75、≤1.0m 55,更大偏差继续扣分,缺项记 0;
  总分按桩位 60% + 车道 40% 加权。
- 教练复核:逐项改分、写评语、确认出最终分;系统分与复核分并行展示。
- 导出(`src/lib/exportCsv.ts`,UTF-8 BOM,Excel 直接打开):
  全员成绩单汇总;按人的成绩单 + 错题清单(偏差 > 0.3m 或缺项)。
- 任务、提交、复核结果、图层覆盖项均通过 localStorage 持久化。

```

  types.ts            类型与五层元数据
  store.ts            Zustand 全局状态 + localStorage 持久化
  data/generator.ts   种子随机 mock 数据(1.07 万要素 + 网格索引)
  lib/spatial.ts      网格查询、框选/套索、外接框
  lib/grading.ts      偏差计算与自动评分规则
  lib/exportCsv.ts    成绩单/错题清单 CSV 导出
  three/symbols.ts    9 种顶视符号几何体
  three/FieldScene.ts three.js 场景引擎(分块/LOD/剔除/拾取/交互)
  components/         左栏、地图、右栏(属性/任务/成绩)UI
smoke/
  e2e.ts              Playwright 36 项端到端断言
  shots.ts            三级 LOD 与高亮截图脚本
```

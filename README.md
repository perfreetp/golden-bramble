# 营地夜间照明布光预览工具

面向青少年营地的二维夜间照明设计工具。基于 **SolidJS + SVG + D3** 实现，在画布上布置营位并拖入灯具，实时计算等照度分布、软阴影与区域达标情况，并附带施工工单流转看板。

## 启动

```bash
npm install
npm run dev      # 开发服务器（默认 http://127.0.0.1:5173）
npm run build    # 生产构建到 dist/
npm run preview  # 预览生产构建
node tests/engine.test.js   # 光照引擎测试（28 项）
```

## 功能清单

### 布光工作台
- **场地元素**：帐篷区（含营位边线）、篝火场、步道、篮球场、水房、围栏、树冠。
- **灯具库拖入**：庭院灯、投光灯、地脚灯、太阳能壁灯（壁灯仅吸附围栏/外墙）。
  HTML5 拖放到画布，靠近边线时自动**吸附对齐**并提示吸附的边线名称。
- **灯具参数**：色温 2700–6500K、功率、挂高、照射半径、光束角，定向灯可调朝向；
  支持常开/定时/关闭三种模式，可复制、删除。
- **光照模型**（`src/engine.js`）：
  - 多灯按距离衰减（余弦定律 + 光束角光强分布）线性叠加；
  - 树冠、帐篷顶、围栏三类挡光体形成软阴影，半影宽度随**发光面尺寸**和**灯—挡光体—测点距离**变化；
  - 高挂灯可部分越过树冠/围栏，矮灯遮挡更强；
  - 照射半径边缘平滑截止。
- **时间轴**：18:00 傍晚 → 23:00 熄灯，太阳/月亮高度角、环境光、定时灯具开启数量联动，
  地面等照度色阶实时重算（d3-contour 等值面）。
- **暗区分析**：低于 20 lx 的网格以红色斜线标出；点击暗区自动选中最近灯具，
  并给出吸附到边线的建议补灯点，一键放置。
- **右侧照度面板**：各区域平均/最低照度、目标值、达标判定、暗区占比，附等照度色阶图例。
- **导出**：灯具清单与参数、区域照度统计导出 JSON；灯具清单导出 CSV（Excel 可直接打开）。

### 工单看板（`#orders`）
- 前台录入营区照度要求 → 派工给师傅 → 师傅提交完工 → 质检抽查；
- 质检不合格打回返工，可重新提交，全程流转记录留痕；
- 看板统计每位师傅的总工单、已合格、在施工、返工次数与返工率。
- 工单与灯具布置分别持久化在 `localStorage`。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `src/model.js` | 场地/灯具/挡光体数据、时间轴与色阶常量 |
| `src/engine.js` | 照度网格、光束衰减、软阴影锥、d3-contour 等值面、区域统计、吸附与补灯建议 |

| `src/App.jsx` | 灯具状态、标签页、导出、本地持久化 |

## 物理建模说明

画布按 **10 单位 = 1 米** 换算。水平面照度采用中心照度 `E₀ = η·Φ/(π·h²)`（含利用系数修正），
配合光束角余弦光强分布 `cosⁿθ`；阴影用统一的锥形遮挡模型，挡光体在光源视角下展开为阴影锥，
半影宽度 `w = S·(L₂/L₁)`（S 为发光面等效尺寸，L₁/L₂ 为灯到挡光体、挡光体到测点的距离）。
该模型为设计预览用途的工程近似，非严格光度学仿真。
